# Splat Darkroom — mobile

Film emulation for iPhone photos, as a home-screen web app.

**Install:** open the GitHub Pages link in Safari → Share → *Add to Home Screen*.

Colour film models: [spektrafilm](https://github.com/andreavolpato/spektrafilm) by Andrea Volpato — profiles and LUTs licensed CC BY-SA 4.0 (see `data/SPEKTRAFILM_LICENSE.txt`). Black-and-white film/paper models, grain, halation and app: Daniel S. Workman / Splat Darkroom.
